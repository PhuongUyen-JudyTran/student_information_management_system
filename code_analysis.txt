## 3. SIMS.Application — Tầng Application (Business Logic)

### 3.1 AuthService — Xác thực & quản lý tài khoản

[AuthService.cs](file:///c:/Users/Trant/OneDrive/Desktop/WebAppAssigntment/App/SIMS.Application/AuthService.cs)

| Phương thức | Chức năng | Luồng xử lý |
|-------------|-----------|-------------|
| `LoginAsync(username, password)` | Đăng nhập | 1. Tìm user theo username → 2. Hash password nhập vào → 3. So sánh hash → 4. Trả về User hoặc null |
| `RegisterUserAsync(...)` | Đăng ký user mới | 1. Sinh ID (prefix `STD`/`FAC`/`ADM` + 5 ký tự GUID) → 2. UserFactory tạo đối tượng → 3. Hash password → 4. Gán thuộc tính con → 5. Validate → 6. Lưu vào repo |
| `DeleteUserAsync(id)` | Xóa user | 1. Xóa user → 2. **Cascade delete**: xóa tất cả enrollment của user đó |

### 3.2 StudentService — Quản lý sinh viên

[StudentService.cs](file:///c:/Users/Trant/OneDrive/Desktop/WebAppAssigntment/App/SIMS.Application/StudentService.cs)

| Phương thức | Chức năng | Luồng xử lý |
|-------------|-----------|-------------|
| `GetStudentProfileAsync(studentId)` | Xem hồ sơ | 1. Lấy Student → 2. Lấy Enrollments → 3. **Tính GPA real-time** (duyệt từng enrollment, lookup course credits, quy đổi grade A=4.0→F=0.0) → 4. Gán AcademicRecord |
| `RegisterStudentAsync(student)` | Đăng ký SV | 1. Validate → 2. Add → 3. **Auto-enroll** (tự động ghi danh) |
| `EnrollInCourseAsync(studentId, courseId)` | Ghi danh thủ công | Kiểm tra student + course tồn tại → tạo Enrollment → validate → add |
| `AutoEnrollCoursesAsync(studentId)` | Tự động ghi danh | 1. Lấy profile đầy đủ → 2. Tìm strategy phù hợp (`_strategies.FirstOrDefault(s => s.CanApply(...))`) → 3. Gọi `AssignCourses()` → 4. Add từng enrollment |

#### Hàm `ConvertGradeToPoint` (private):
```
A → 4.0 | B → 3.0 | C → 2.0 | D → 1.0 | F → 0.0 | khác → -1.0 (bỏ qua)
```

### 3.4 Strategy Pattern — Auto-enrollment

```mermaid

        <<interface>>

## 4. SIMS.Infrastructure — Tầng Infrastructure (Lưu trữ CSV)

### 4.1 CsvContext — Trung tâm I/O

[CsvContext.cs](file:///c:/Users/Trant/OneDrive/Desktop/WebAppAssigntment/App/SIMS.Infrastructure/Data/CsvContext.cs)

| Phương thức | Chức năng |
|-------------|-----------|
| Constructor | Đọc đường dẫn thư mục data từ `IConfiguration["DataSettings:CsvFolder"]`, fallback về `{BaseDirectory}/Data`. Tạo thư mục nếu chưa có |
| `ReadLinesAsync(filename)` | Đọc tất cả dòng trong file CSV (có lock) |
| `WriteAllLinesAsync(filename, lines)` | Ghi toàn bộ nội dung vào file (qua file `.tmp` → rename, có lock) |

> [!TIP]
> **Atomic write pattern**: Ghi vào file `.tmp` trước, sau đó `File.Move` overwrite file gốc. Tránh corruption nếu crash giữa chừng.

### 4.2 CsvHelper — Parse/Format CSV

[CsvHelper.cs](file:///c:/Users/Trant/OneDrive/Desktop/WebAppAssigntment/App/SIMS.Infrastructure/Data/CsvHelper.cs)

| Phương thức | Chức năng |
|-------------|-----------|
| `ParseLine(csvLine)` | Parse 1 dòng CSV → `List<string>`. Xử lý quoted fields, escaped double-quotes |
| `FormatLine(fields)` | Format `IEnumerable<string>` → 1 dòng CSV. Auto-quote nếu chứa `,`, `"`, `\n` |

### 4.3 File Locking — Thread Safety

[CsvFileLockManager.cs](file:///c:/Users/Trant/OneDrive/Desktop/WebAppAssigntment/App/SIMS.Infrastructure/Locking/CsvFileLockManager.cs)

```
ConcurrentDictionary<string, SemaphoreSlim> → mỗi filename 1 semaphore (1,1)
AcquireLockAsync → WaitAsync trên semaphore → trả về IDisposable Releaser
Releaser.Dispose → Release semaphore
```

> [!NOTE]
> Pattern **async lock** sử dụng `SemaphoreSlim` kết hợp `IDisposable` để dùng trong `using` block, đảm bảo thread-safe khi đọc/ghi file CSV.

## 6. Design Patterns đã sử dụng

| Pattern | Vị trí | Mô tả |
|---------|--------|--------|
| **Factory Method** | `UserFactory` | Tạo đúng subtype User dựa trên UserRole |
| **Strategy** | `ICourseAssignmentStrategy` + 2 impl | Auto-enroll khác nhau cho Standard vs Honors student |
| **Repository** | 4 interface trong Domain + 4 CSV impl trong Infrastructure | Tách biệt logic truy xuất dữ liệu |
| **Template Method** | `User.Validate()` (virtual) → subclass `override` gọi `base.Validate()` | Chuỗi validation kế thừa |
| **Dependency Injection** | Extension methods `AddApplicationServices()` / `AddInfrastructureServices()` | Đăng ký toàn bộ services qua DI container |

    C -->|"Program KHÔNG chứa 'Honors'"| E[StandardAssignmentStrategy]
    
    D --> F["Lấy tối đa 4 môn nâng cao<br/>(Credits≥4 hoặc có số 3/4/5 trong ID)"]
    E --> G{"Program chứa 'IT'/'Information'?"}
    G -->|Có| H["Lấy tối đa 3 môn prefix CS/SE"]
    G -->|Không| I["Lấy tối đa 3 môn prefix BUS"]
    
    F --> J[Tạo Enrollments → AddAsync]
    H --> J
    I --> J
```
